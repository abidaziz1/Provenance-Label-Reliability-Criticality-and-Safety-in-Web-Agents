# Security and sensitive data

Do not paste credentials, personal correspondence, or private page captures into a public issue or pull request.

For a suspected credential leak, use the contact options on [Abid Aziz's GitHub profile](https://github.com/abidaziz1). Revoke exposed credentials at the provider; deleting a file does not remove it from Git history.

The scanner detects known patterns. A clean scan does not establish that every kind of sensitive data is absent. Treat page and dataset text as untrusted input, especially in annotation pages and model observations.

This is research software in development. Report ordinary reproducibility failures through GitHub issues with sanitized logs.
